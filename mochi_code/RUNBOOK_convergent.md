# 인수인계: 수렴 검증 상관 측정

**부탁드리는 일:** 이미 학습이 끝난 체크포인트를 읽어서 표 하나를 뽑아주시면 됩니다.
**학습은 하지 않습니다.** GPU에서 코호트당 몇 분이면 끝납니다.

---

## 1. 왜 이걸 재는가

MOCHI는 오믹스 하나가 통째로 없는 환자의 그 오믹스를 채워 넣는 모델입니다.
지금까지 나온 결과를 한 줄로 요약하면 이렇습니다.

> 보간 정확도는 기존 방법(MIMIR)에 못 미치고, NMF 생물학 사전지식을 넣는
> 세 가지 경로는 전부 무효이거나 오히려 해로웠다.

그래서 논문의 방향을 "더 정확하다"가 아니라 **"언제 믿으면 안 되는지 알려준다"**로
바꾸려고 합니다. 예를 들어 단백질을 채울 때 오차가 0.98인데, 이건 그냥 평균값을
찍은 것과 거의 같은 수준입니다. 문제는 **쓰는 사람이 그걸 모른다**는 겁니다.
모델이 말없이 쓸모없는 값을 내보내고, 하위 분석이 그걸 그대로 씁니다.

그래서 묻고 싶은 것은 하나입니다.

> **정답을 보지 않고도, 이 보간값이 믿을 만한지 알 수 있는가?**

이번 측정이 그 답을 냅니다. 답이 "예"면 논문의 뼈대가 되고,
"아니오"면 이 방향을 접고 다른 구조로 갑니다. **어느 쪽이든 결론이 납니다.**

---

## 2. 무엇을 재는가

정답을 안 보고 계산할 수 있는 **신호 두 개**를 만들고,
그게 **실제 오차와 상관이 있는지** 봅니다.

### 신호 1 — `cycle` (특징 공간 순환 일치) ← **주력**

RNA를 채웠다고 합시다. 그 채운 RNA를 **다시 입력으로 넣어서**, 이번엔
단백질을 역으로 예측해 봅니다. 단백질은 실제로 관측된 값이 있으니 정답을 압니다.

역예측이 정답과 크게 어긋나면 → 처음 채운 RNA가 이상하다는 뜻입니다.

### 신호 2 — `coef` (NMF 성분 좌표 불일치) ← **참고용, 단독 채택 금지**

채운 값의 실제 성분 구성 `W(x̂)` 와, 모델이 예측했던 구성 `Ŵ` 를 비교합니다.

**주의: 이건 검증 신호가 아닐 가능성이 높습니다.** `Ŵ` 는 학습 중에 참값의
성분 구성 `W(x)` 를 맞히도록 훈련됐습니다. 그게 잘 됐다면

```
‖W(x̂) − Ŵ‖  ≈  ‖W(x̂) − W(x)‖
```

이고, 오른쪽은 **보간 오차를 NMF 좌표로 다시 쓴 것**일 뿐입니다. 그러면 실제
오차와 상관이 높은 게 당연하고, 검증했다고 말할 수 없습니다.

스크립트가 이 가설을 직접 잽니다 (`coef_tautology` 열). 이 값이 높으면
`coef` 는 오차의 재표현이므로 **근거로 쓰지 않습니다.**

### 대조 두 개 — 이게 없으면 위 신호를 믿을 수 없습니다

맞추기 어려운 환자는 **어느 방향으로 예측해도** 오차가 큽니다. 그래서 신호가
오차와 상관 있어도, "이 보간이 틀렸다"가 아니라 "이 환자가 어렵다"일 수 있습니다.

| 대조 | 뜻 |
|---|---|
| `dist_mean` | 관측 오믹스가 코호트 평균에서 떨어진 정도. **모델을 전혀 쓰지 않습니다** |
| `self_recon` | 관측 오믹스를 자기 자신으로 복원한 오차. 환자 난이도 |

`cycle` 이 이 대조들을 통제하고도 오차를 가리켜야 신호로 인정합니다.
실제로 합성 데이터 시험에서 `cycle` 의 raw 상관이 0.838이었는데 `dist_mean` 이
0.908이라, 난이도를 빼자 편상관이 −0.056으로 **사라졌습니다.** 대조 없이 봤으면
잘못 채택했을 상황입니다.

## 4. 실행

코호트 세 개를 차례로 돌리면 됩니다. 복사해서 붙여넣으시면 됩니다.

```bash
cd /home/dyan/nmf/mochi_code
source /home/dyan/nmf/.nmf/bin/activate

for COH in brca luad kirc; do
  R=results/current/lr_ctl
  python -u eval_convergent.py \
    --data_dir processed_data/gate_$COH \
    --gpu 0 \
    --out  $R/convergent_$COH.tsv \
    --dump $R/convergent_${COH}_samples.tsv \
    --runs \
      ctl_base=$R/ctl_base/${COH}_hybrid/nmf_tf_best.ckpt \
      w0=$R/w0/${COH}_hybrid/nmf_tf_best.ckpt \
      nmf0=$R/nmf0/${COH}_hybrid/nmf_tf_best.ckpt \
      lw0_nmf0=$R/lw0_nmf0/${COH}_hybrid/nmf_tf_best.ckpt \
      none=$R/none/${COH}_hybrid/nmf_tf_best.ckpt \
    2>&1 | tee $R/convergent_$COH.log
done
```

없는 체크포인트는 알아서 건너뛰고 메시지를 남깁니다. 중간에 멈추지 않습니다.

## 5. 결과 읽는 법

스크립트가 마지막에 이런 판정을 찍습니다.

```
=== 판정 ===
  ctl_base     cycle      평균 spearman=+0.816  편상관=+0.228  top20_recall=0.600
                          →  약함 — 코호트 셋 모두에서 같은 방향인지 확인 필요
  ctl_base     coef       평균 spearman=+0.492
                          →  참 NMF 오차와 순위상관 +0.91 — 오차의 재표현, 근거로 쓰지 말 것
  ctl_base     dist_mean  평균 spearman=+0.812  (대조 기준선)
  ctl_base     self_recon 평균 spearman=+0.808  (대조 기준선)
```

| 항목 | 뜻 |
|---|---|
| `spearman` | 신호와 실제 오차의 순위 상관. 무작위면 0. **이것만 보면 안 됩니다** |
| `partial_min` | 두 대조를 각각 통제한 편상관 중 낮은 쪽. **이게 핵심 숫자입니다** |
| `top20_recall` | 신호로 상위 20%를 거를 때 진짜 최악 20%를 몇 비율 잡는가. 무작위면 0.20 |
| `coef_tautology` | `coef` 가 참 NMF 좌표 오차와 얼마나 같은 순위인가. 높으면 동어반복 |

판정 기준 (`cycle` 기준, 자동으로 붙습니다):

- `partial_min ≥ 0.30` → 난이도를 빼고도 신호가 남음. 보강 문장으로 채택
- `0.15 ~ 0.30` → 약함. 코호트 셋 모두 같은 방향인지 확인 필요
- `< 0.15` → 난이도로 설명됨. 신호 아님

**`coef` 는 아무리 높아도 단독으로 채택하지 않습니다.** 참고 정보입니다.

### 나올 수 있는 경고 하나

```
[주의] rna: 계수 머리가 사실상 상수다 (환자 간 표준편차 2.4e-08).
       lambda_w=0.0 런이면 정상이며, 이때 coef 신호는 검증이 아니라
       '코호트 평균에서의 거리'를 잰다.
```

**이건 오류가 아닙니다.** `w0`, `lw0_nmf0`, `none` 세 조건은 계수 학습을 꺼놓고
돌린 것이라 이렇게 나오는 게 맞습니다. 그 세 조건에서는 `coef` 줄을 무시하고
`cycle` 줄만 보시면 됩니다.

`coef` 신호가 의미 있는 조건은 **`ctl_base` 와 `nmf0`** 둘뿐입니다.

## 8. 결과가 뜻하는 것 (참고)

보는 조건은 `none` 과 `nmf0` 입니다. 이 둘은 해롭다고 측정된 NMF 항이 꺼져 있어
논문에서 쓸 구조에 가깝습니다.

- **`cycle` 의 `partial_min` 이 세 코호트에서 일관되게 0.3 이상이면**
  → "언제 믿으면 안 되는지 알려준다"를 **보강 문장**으로 넣습니다.
  논문의 주장을 바꾸는 것이 아니라, 기존 다섯 arm 결과 위에 한 절을 더하는 것입니다.
- **약하거나 코호트마다 방향이 다르면**
  → 보강 없이 닫습니다. 논문은 기존 다섯 arm 표로 갑니다.
- **`coef` 가 높게 나와도** → 그것만으로는 아무것도 바꾸지 않습니다.
  `coef_tautology` 를 같이 보고, 높으면 오차의 재표현으로 기록만 합니다.

논문의 뼈대는 어느 경우에도 이미 나와 있는 다섯 arm 결과입니다. 칸 결측은
자기 은닉이 이득을 만들고, 블록 재구성은 MIMIR가 앞서고, NMF 잔차와 출력단
NMF 손실은 환자 분할을 나쁘게 만들고, 토큰과 계수 손실은 오차를 줄이지 않는다.
**이번 측정은 거기에 한 문장을 더할 수 있는지만 봅니다.**
