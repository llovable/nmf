# 인수인계: 5안 사다리 학습

**부탁드리는 일:** 스크립트 하나를 돌리고 요약표를 보내주시면 됩니다.
GPU에서 **약 한 시간**입니다. 중간에 판단하실 일은 없습니다.

---

## 0. 먼저 — 지난번 중단 사유가 잘못됐습니다

지난번에 "1단계가 0단계를 이기지 못했으니 멈춘다"로 정리됐는데,
**그 판정 기준을 제가 잘못 설계했습니다.** 두 가지가 틀렸습니다.

**첫째, 분리는 성능 장치가 아닙니다.** 공유/전용 분리는 블록 경로에서 정보를
빼기만 하고 대신 주는 게 없습니다. 이게 혼자서 오차를 줄일 이유가 없습니다.
분리의 목적은 뒤 단계가 설 **기반**입니다 — 깨끗한 공유 좌표가 있어야
경로별 모듈 배치도, 내용 있는 성분 토큰도 의미가 생깁니다.

그래서 **1단계가 0단계와 같게 나오는 것은 통과입니다.** "공짜로 얹힌다"가
통과 조건이고, 실제로 그렇게 나왔습니다(0.8832 대 0.8845).

**둘째, 0.0013은 단일 시드입니다.** 이 프로젝트에서 이미 같은 크기의 차이를
잡음으로 판단한 적이 있습니다(0.8939 대 0.8952). 같은 기준이면 0.0013으로는
어느 방향으로도 말할 수 없습니다. 그래서 이번 스크립트는 **시드 3개**를 돌리고
표준편차를 같이 냅니다.

**셋째, 2·3단계는 한 번도 돌아간 적이 없습니다.** 지금까지 측정된 실패는 전부
*다른* 구성입니다. 다섯 arm 표도, 용량 스윕도, `lr_auxw`도 5안이 아닙니다.

그래서 이번에 돌리는 것은 **아직 평가된 적 없는 설계**입니다.

## 1. 무엇을 재는가

네 단계를 **한 번에 하나씩만** 바꿔 올라갑니다. 그래야 차이가 어느 부품 탓인지
갈립니다. (λ_w 2.0 대 0.1로 용량 표가 교란됐던 것과 같은 실수를 피하려는 것입니다.)

| 단계 | 구성 | 갈리는 것 |
|---|---|---|
| `s0` | 평균 융합, 토큰 없음, 분리 없음 | 기준선 |
| `s1` | + 공유/전용 분리 | **분리만의 효과** |
| `s2` | + 칸 경로에만 Transformer (블록은 평균 유지) | **경로 배치만의 효과** |
| `s3` | + 내용 있는 성분 토큰 | **토큰만의 효과** |

네 단계 공통으로 **해롭다고 측정된 항은 전부 꺼져 있습니다** —
저랭크 잔차 없음(`--aux_w_only`), 출력단 NMF 손실 0(`--lambda_nmf 0`),
GAN 0(`--gan_to_mse 0`).

각 단계가 무엇인지 한 줄로:

- **분리(`s1`)** — 오믹스별 은닉을 반으로 잘라, 다른 오믹스로 건너가는 경로에는
  앞 절반만 넣습니다. 뒤 절반은 자기 오믹스 재구성과 칸 결측에만 쓰입니다.
  오믹스 고유의 기술적 변동이 번역을 오염시키지 못하게 하려는 것입니다.
- **경로 배치(`s2`)** — 블록 결측(오믹스 통째 없음)과 칸 결측(군데군데 없음)에
  서로 다른 모듈을 씁니다. 이전 재학습에서 블록은 평균이, 심한 결측의 칸은
  attention이 앞섰는데, 그 배치가 코드로 표현 불가능했습니다. 이번에 가능해졌습니다.
- **성분 토큰(`s3`)** — NMF 성분 토큰을 계수 스칼라 하나가 아니라
  `인코더(W[j]·H[j])`로 만듭니다. 기존 인코더를 재사용하므로 새 파라미터가 없습니다.

## 3. 실행

```bash
cd /home/dyan/nmf/mochi_code
source /home/dyan/nmf/.nmf/bin/activate
GPU=0 bash scripts/train_stage5.sh 2>&1 | tee ~/stage5.log
```

## 4. 결과 읽는 법

끝나면 이런 표가 찍힙니다.

```
코호트                   s0                s1                s2                s3
brca         0.8832±0.0021     0.8845±0.0018     0.8790±0.0019     0.8801±0.0024
```

**표준편차가 핵심입니다.** 평균 차이가 표준편차보다 작으면 같은 것입니다.

| 단계 | 통과 조건 |
|---|---|
| `s1` | **`s0`와 표준편차 안에서 같으면 통과.** 분리는 기반이지 성능 장치가 아닙니다 |
| `s2` | `s1`을 **표준편차를 넘게** 줄여야 경로 배치가 값을 한 것입니다 |
| `s3` | `s2`를 **표준편차를 넘게** 줄여야 성분 토큰이 값을 한 것입니다 |

**`s1`이 `s0`보다 살짝 나빠도 기각이 아닙니다.** 표준편차 안이면 통과입니다.
지난번 0.0013은 정확히 이 경우였습니다.

미리 말씀드리면 **`s3`의 기대는 낮습니다.** 빈 토큰 60개를 뺐을 때 군집이
좋아진 적이 있고, 중복 논증도 절반은 유효합니다. `s2`까지만 깨끗하게 나와도
"두 결측 체제에 서로 다른 모듈이 필요하다"는 문장이 서고, 그건 지금 논문에
없는 결과입니다.

## 7. 결과가 뜻하는 것

- **`s2`가 `s1`을 표준편차 넘게 줄이면** → 경로별 모듈 배치가 본편이 됩니다.
  "두 결측 체제에 다른 모듈이 필요하다"를 본문 결과로 씁니다.
- **`s2`도 `s3`도 `s1`과 같으면** → 5안을 접습니다. 다만 이번엔
  "설계를 구현해 세 코호트 세 시드로 평가했고 차이가 없었다"로 쓸 수 있습니다.
  지난번의 "안 돌려봤다"와는 다른 문장이고, 음성 결과로 논문에 들어갑니다.
- **어느 경우든** 논문의 뼈대는 이미 나와 있는 다섯 arm 표입니다.
  이번 결과는 그 위에 얹는 한 절이지 그것을 대체하지 않습니다.

세 경우 모두 다음 행동이 정해집니다. 그래서 이 한 시간이 값어치가 있습니다.
