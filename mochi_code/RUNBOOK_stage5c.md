# 인수인계: 칸 경로 사다리 (5안 후속)

**부탁드리는 일:** 스크립트 하나를 돌리고 요약표를 보내주시면 됩니다.
GPU에서 **약 40분**입니다. 중간에 판단하실 일은 없습니다.

---

## 0. 왜 다시 돌리는가 — 지난 s2·s3는 측정 자체가 불가능했습니다

지난 사다리에서 이런 표가 나왔습니다.

| 코호트 | s0 | s1 | s2 | s3 |
|---|---|---|---|---|
| BRCA | 0.8819±0.0010 | 0.8813±0.0022 | 0.8813±0.0022 | 0.8813±0.0022 |
| LUAD | 0.8888±0.0002 | 0.8874±0.0007 | 0.8874±0.0007 | 0.8874±0.0007 |
| KIRC | 0.7824±0.0019 | 0.7837±0.0026 | 0.7837±0.0026 | 0.7837±0.0026 |

`s1`·`s2`·`s3`가 **표준편차까지 같습니다.** 이건 "차이가 없다"가 아니라
**같은 모델**이라는 뜻입니다. 확인해 보니 그랬습니다.

```
s1 vs s2:  블록 출력 max|diff| = 0.000e+00   |   칸 출력 max|diff| = 9.6e-02
s1 vs s3:  블록 출력 max|diff| = 0.000e+00   |   칸 출력 max|diff| = 5.7e-02
```

원인은 이렇습니다.

| | 무엇을 부르나 | 경로 |
|---|---|---|
| 학습 LOO 손실 | `loo_parts(...)` | **블록** |
| 검증 지표 `block_zrmse` | `predict_nmf_tf(missing=tgt)` | **블록** |
| `mixed_reconstruct` (칸) | `predict_nmf_tf(missing=None)` 에서만 | **칸** |

`cell_attn` 과 `content_tokens` 는 **칸 경로에만** 작동합니다. 그런데 학습도
검증도 블록 경로만 씁니다. 그래서 두 옵션은 학습에도 평가 지표에도 영향을 줄
수 없었고, 같은 시드로 같은 가중치가 나왔습니다. **36런 중 24런이 s1의 복사본**
이었습니다.

**사다리를 그렇게 설계한 것이 잘못이었습니다.** 칸 경로를 바꾸는 단계를 만들어
놓고 판정 지표를 블록으로 뒀습니다. 돌려주신 결과에서 유효한 것은 `s0` 대 `s1`
하나이고, 그건 **통과**입니다 — 세 코호트 모두 표준편차 안입니다.

### 더 큰 구멍이 하나 드러났습니다

학습 손실에 **칸 결측 항이 아예 없었습니다.** 제목은 `Hybrid Imputer` 인데
두 체제 중 블록만 학습하고, 칸 결측은 평가만 했습니다. 칸 경로는 추론에서
처음 쓰이고 있었습니다.

---

## 1. 무엇을 고쳤나

두 가지입니다. **둘 다 기본값 off라, 지금까지의 모든 결과는 그대로 유효합니다.**

**`--lambda_cell`** — 칸 결측을 학습 손실에 넣습니다. 인위로 가린 칸을
자기 은닉 + 융합 혼합으로 복원하고 채점합니다.

**`--select_on cell`** — 조기 종료를 칸 지표로 바꿉니다. 칸을 학습해놓고
블록으로 체크포인트를 고르면 어긋납니다. 가리는 자리는 시드로 고정해
에폭 간 비교가 흔들리지 않습니다.

효과는 확인했습니다. 칸 손실을 켜니 `cell_attn` 이 학습 궤적을 실제로 가릅니다.

```
cell_attn=off   loo=0.9649  cell=0.5707   →  best cell zRMSE 1.2335
cell_attn=on    loo=0.9315  cell=0.5771   →  best cell zRMSE 1.2310
```

## 2. 이번에 재는 것

| 단계 | 구성 | 묻는 것 |
|---|---|---|
| `c0` | 칸 융합 = 평균, 토큰 없음 | 기준선 |
| `c1` | + 칸 경로에 Transformer | **경로 배치가 값을 하는가** |
| `c2` | + 내용 담은 성분 토큰 | **토큰이 값을 하는가** |

블록 경로는 세 단계 모두 **평균 + 분리 켬**으로 고정입니다. `s0..s3` 에서
확정된 설정이라 다시 흔들지 않습니다. 공통으로 저랭크 잔차 없음,
출력단 NMF 손실 0, GAN 0 입니다.

## 5. 결과 읽는 법

```
코호트                           c0                        c1                        c2
brca         0.7412±0.0031 (0.881)     0.7380±0.0028 (0.882)     0.7391±0.0035 (0.881)
```

앞이 **칸 val z-RMSE**(이번 판정 지표), 괄호가 블록 값(참고용)입니다.

| 단계 | 통과 조건 |
|---|---|
| `c1` | `c0` 를 **표준편차를 넘게** 줄여야 경로 배치가 값을 한 것입니다 |
| `c2` | `c1` 을 **표준편차를 넘게** 줄여야 성분 토큰이 값을 한 것입니다 |

**괄호 안 블록 값은 세 단계가 비슷해야 정상입니다.** 크게 벌어지면 블록 경로가
의도치 않게 영향을 받은 것이니 알려주세요.

지난번처럼 **세 단계 숫자가 완전히 같게 나오면 그때도 알려주세요.** 이번엔
그럴 수 없어야 정상이고, 같다면 설정이 안 먹은 것입니다.

## 8. 결과가 뜻하는 것

- **`c1` 이 `c0` 를 표준편차 넘게 줄이면** → "두 결측 체제에 서로 다른 모듈이
  필요하다"가 본문 결과가 됩니다. 지금 논문에 없는 문장입니다.
- **`c1`·`c2` 가 `c0` 와 같으면** → 5안을 닫습니다. 다만 이번엔
  "구현해서 세 코호트 세 시드로 평가했고 차이가 없었다"로 쓸 수 있습니다.
- **어느 경우든** 뼈대는 이미 나와 있는 다섯 arm 표와, s0·s1 에서 확정된
  "분리는 공짜로 얹힌다"입니다. 이번 결과는 그 위에 얹는 한 절입니다.

`λ_cell=1.0` 은 측정된 값이 아니라 선택입니다. 전부 null 로 나오면 그게 후보
교란이니, 그땐 `LAMBDA_CELL=0.3 bash scripts/train_stage5c.sh` 로 한 번 더
보는 것이 다음 수순입니다.
